# Single-Centred Black Holes in the Composite CHL Models Have Positive Index

Deep Bhattacharjee

LaTeX source (`paper/`), figures and verification code for the paper. Run every check with

    cd code && python3 verify.py 40

(Python 3 with mpmath, numpy, scipy and sympy). The figures are made by `figures/make_figs.py` (matplotlib).
